# Software requirements and SDLC report

- [Final PDF](../output/pdf/Software_Process_Report.pdf)
- [Editable content](Software_Process_Report.md)

The report documents requirements, architecture, data/SNMP definitions, prediction,
control, the SDLC, verification, deployment, risks, and traceability. It describes
an implementation baseline, not proof of physical network improvement.

Machine-specific cleanup ledgers and rendering metadata remain local. To regenerate
the PDF, install reportlab and pymupdf and run tools/build_software_report.py from
the project root. Generated page images are internal QA artifacts.
